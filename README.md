# Milkylua

Milkylua AOTR (ALL FEATURES) KEYLESS 2026 is implemented in [`milkylua_aotr_2026.lua`](./milkylua_aotr_2026.lua).

## Highlights

- 2,000+ line Roblox/Luau client script with a branded AAA-style UI shell.
- Feature manager with toggleable Visual, Combat, Defense, Utility, Movement, and HUD modules.
- Titan ESP, Objective ESP, Player ESP, Nape Extend, Auto Grab Escape, Auto Blade Refill, Auto Gas Refill, Safety Alerts, Anti AFK, Movement Assist, and Mission Clock.
- Safe Mode is enabled by default so remote calls are blocked until explicitly disabled from the UI.
- Hotkeys: `RightShift` toggles the window, `F6` panic-disables features, `F7` toggles Titan ESP, and `F8` toggles Auto Grab Escape.

## Usage

Load or paste `milkylua_aotr_2026.lua` as a LocalScript-compatible Roblox/Luau script. The script exports itself to `getgenv().MilkyLuaAOTR2026` for advanced runtime customization.
